Menghitung jumlah vertices pada sebuah Layer¶

[ Download PDF A4 Letter ]

QGIS tidak mempunyai fungsi built-in untuk menghitung jumlah vertices untuk setiap fitur pada sebuah layer. Tetapi sebuah plugin berguna yang bernama Vertices Counter mengisi kekosongan ini dan menambahkan beberapa fitur yang berguna pula.

Prosedur¶

  1. Cari dan Install plugin Vertices Counter . lihat docs/using_plugins utnuk lebih detail dalam menginstall plugins di QGIS.

  1. Buka layer poligon atau garis mana saja di QGIS. Kemudian akses Vector ‣ Vertices Counter ‣ Vertices Counter.

  1. Di settingan awal, layer yang aktif akan terpilih dari Layer Selection . Anda mungkin memilih layer yang sudah dibuka lainnya atau membuka layer langsung dari disk. Plugin ini mempunyai opsi bernama Create new column yang dapat menambah angka jumlah vertices sebagai attribut untuk setiap fitur. Ini berguna untuk banyak kasus, jadi kita dapat memilih opsi tersebut. Sekarang klik tombol Count Vertices dan bagian Results akan terkumpul dengan jumlah sudut untuk setiap fitur. Anda bahkan dapat melihat Total Vertices yang terlampir di samping

  1. Kembali ke jendela utama QGIS, mari kita verifikasi jika sebuah kolom baru ditambahkan ke layer kita, Klik kanan pada layer dan pilih Open Attribute Table.

  1. Seperti yang anda lihat, sebuah kolom bernama Vertices akan ditambahkan di akhhir nilai merepresentasikan jumlah verteks untuk setiap fitur. Kolom ini dapat berguna jika anda ingin melakukan sebuah query seperti Select all features with Vertices > X.
